# ADR 0006: Cipher as an in-app companion

**Decision:** keep the previous app's Cipher (persona, 15 moods, trust meter, tones) and adapt it to DAREWIRE: a handler who helps with dare ideas, nerves and tactics. Gemini is called only from the server with a structured JSON schema (messages, mood, trust delta). Crisis language is handled deterministically before any model call. Chat memory is device-local; the server is stateless for chat. Cipher is a painted character (glossy body, glass visor, big eyes, cheeks, mouth) so that mood, touch and talking can drive the expression every frame; tapping him squishes him and he follows your finger with his eyes. **Cost:** one model call per user message (rate-limited). **Alternative rejected:** server-side chat history: it would make DAREWIRE a custodian of intimate conversations.
