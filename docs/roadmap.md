# Roadmap

**Next, in order of value:** run the Flutter app on a device and fix first-run issues · shared limiter and session ownership in Redis for multi-instance · push notifications for "your queued turn is up" · server-side re-evaluation of the policy lexicon in more languages · real age assurance · moderator tooling in a web admin · replay of finished rounds from `game_events` · LiveKit egress with explicit consent for highlights · load test on real infrastructure.

**Deliberately not built:** recording or storing video, automated nudity/violence video classification, direct messages, payments, public follower graphs.

## Added in the social update
Four themes (Neon, Aurora, Crimson, Spectrum) in a liquid-glass style; DAREWIRE branding without the "AFTERDARK" tag; 20 built-in avatars plus gallery photos; Feed with Live and Dares pages; Duels; daily quests, streaks and a points wallet; Cipher with a tappable face.
